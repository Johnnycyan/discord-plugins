# ChannelCollapser

A Discord plugin for Equicord/Vencord that adds a "Collapse All" button above the channels list.

## Features

- **Collapse All Button**: Adds a button at the top of the channel sidebar that collapses all channel categories with a single click.
- **Category Denylist**: Configure which category names should be excluded from collapsing (e.g., your favorite or frequently used categories).

## Settings

| Setting | Description | Default |
|---------|-------------|---------|
| Denylist | Comma-separated list of category names to NOT collapse | `Top, Current VC, In Progress, Matto Extra` |

## Usage

1. Enable the plugin in your Equicord/Vencord settings
2. Configure the denylist to exclude any categories you want to keep expanded
3. Click the "Collapse All" button at the top of the channel list to collapse all categories except those in your denylist
